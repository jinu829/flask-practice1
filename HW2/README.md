# 📝 Flask Todo App

Flask 기반으로 동작하는 간단한 할 일 관리(Todo) 웹 애플리케이션입니다.

## 🚀 주요 기능

- **할 일 추가**: 새로운 할 일을 목록에 등록합니다.
- **완료 상태 토글**: [완료] 버튼을 눌러 항목에 취소선을 긋거나 해제합니다.
- **할 일 삭제**: [Delete] 버튼을 눌러 선택한 항목을 삭제합니다.

## 🛠 사용 기술 (Tech Stack)

- **Backend**: Python, Flask
- **Frontend**: HTML5, CSS3, Jinja2 Template Engine
