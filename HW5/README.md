## 단계①~④: 한 일과 근거(35쪽표모양)

1. 단계 1 -한 일 : pd.read_csv()로 csv파일을 읽어온 후, pd.to_datetime()을 이용하여 delivery_date, shipping_date, order_date를 날짜로 변환함. -근거 : 날짜 연산(배송 기간 계산 등) 및 월별 집계를 수행하기 위해 데이터 타입을 변환함.
2. 단계 2 -한 일 : df.drop_duplicates()를 통하여 중복된 행을 제거하여 다시 df에 대입한다. -근거 : 금액 소수점까지 완전히 동일한 26쌍의 주문이 중복 입력된 것이 확인되었으므로, 데이터 손실 없이 중복 건만 삭제함.
3. 단계 3 -한 일 : 수량이 100을 초과하는 행(`quantity > 100`)의 수량을 `total_sales / unit_price`로 계산하여 정수로 복원함. -근거 : 해당 22건은 `금액 ≠ 수량 × 단가` 조건에 해당했으나, `금액 ÷ 단가`를 계산했을 때 정확히 딱 떨어지는 정수가 나왔음. 즉, 금액과 단가는 정상이고 수량 칸만 잘못 입력된 오타임이 확인되어 해당 값으로 복원함.
4. 단계 4 -한 일 : df["date_error"] = df["delivery_date"] < df["shipping_date"]로 date-error열을 추가하고, df.to_csv("sales_clean.csv", index=False)로 csv파일을 제작함. -근거 : 어떤 날짜가 틀렸는지 판단할 추가 근거(다른 컬럼)가 없으므로 데이터를 섣불리 고치거나 삭제하지 않고 Flag 컬럼으로 표시만 남겨둠.

## 단계⑤~⑦: 답 각 두줄

1. 단계 5
   배송 기간(date_error 가 아닌 줄)은 평균 22.05일, 중앙값 2일로 크게 다르다. 히스토그램 오른쪽 끝에 364~370일인 줄이 47건 몰려 있어서 평균만 끌어올렸기 때문이다.
   47건이 모두 약 365일 차이라 도착일 연도를 잘못 입력한 것으로 보고 배송 기간 계산에서 제외했다. 이 47건을 빼면 평균이 1.93일로 중앙값 2일과 거의 같아지므로, 보통 배송 기간은 약 2일이다.

2. 단계 6
   아니다. 만족도가 4, 5인 경우가 만족도가 1인 경우와 반품 비율이 크게 차이가 나지 않으며, 만족도가 4인 경우에는 만족도가 1인 경우보다 반품 비율이 높게도 나오기 때문이다.
   만족도 1→5 순서로 7.6% / 12.0% / 7.8% / 8.7% / 6.9%

3. 단계 7
   매출 1위는 가구(28.4억)로, 건수 213건 · 평균 단가 257,323원 · 평균 수량 51.0개로 세 칸 모두 상위권이다. 2위 식품(25.1억)과 비교하면 건수(213 vs 210, +1.4%)와 단가(257,323 vs 255,233원, +0.8%)는 거의 같고, 평균 수량(51.0 vs 47.3개, +7.8%)에서 가장 큰 차이가 난다.
   따라서 가구가 1위인 이유는 어느 한 칸이 압도적이어서가 아니라 건수 · 단가 · 수량이 모두 높은 편이고, 그중 2위와의 차이를 만든 칸은 수량이다. 5위 의류(21.8억)는 평균 단가 · 수량은 가구와 비슷하지만 건수가 170건으로 가장 적어 매출이 가장 낮다.
